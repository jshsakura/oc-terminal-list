# Terminal List 사용 안내

터미네이터가 "어떻게 해요?" 에 답할 때 이 문서만 근거로 씁니다. 여기 없는 버튼이나 설정은
없는 것으로 봅니다.

## 처음 시작

이 화면은 브라우저 안의 터미널입니다. 위쪽 줄이 탭이고, 탭 하나에 칸(pane)을 여러 개 나눠
둘 수 있습니다. 처음 들어오면 터미널 첫 화면에 아직 안 한 준비(GitHub 로그인, git 이름·이메일,
Claude 로그인)가 표시됩니다. 표시된 명령을 그대로 치면 됩니다.

## 로그인

- GitHub: 터미널에 `gh auth login` 을 치고 안내대로 브라우저에서 승인합니다.
- Claude: `claude` 를 치면 처음 한 번 로그인 화면이 나옵니다.
- Codex: `codex login` 을 칩니다.
로그인은 컨테이너를 다시 띄워도 남습니다.

## 탭과 칸

- 칸 나누기: 칸 위쪽 줄 오른쪽의 분할 아이콘을 누르고 오른쪽 또는 아래를 고릅니다.
- 칸 닫기: 칸 위쪽 줄 오른쪽 끝의 `…` 메뉴에서 "터미널 닫기" 를 누릅니다. 그 칸에서 돌던
  작업은 끝납니다.
- 칸을 새 탭으로 떼기: `…` 메뉴의 "새 탭으로 분리" 를 누릅니다.
- 같은 폴더에서 하나 더 열기: `…` 메뉴의 "이 경로에서 새 터미널" 을 누릅니다.

## … 메뉴

칸 위쪽 줄 오른쪽 끝의 `…` 를 누르면 나옵니다.
- 정보: 이 칸의 호스트와 경로, 세션을 보여 줍니다.
- 테마: 이 칸에만 다른 테마를 입힙니다.
- 텍스트로 보기: 화면 내용을 글자로 띄워 복사하기 쉽게 합니다.
- 터미널 새로고침: 화면만 다시 그립니다. 돌던 작업은 그대로입니다.
- 세션 재시작: 돌던 것을 끝내고 같은 폴더에서 셸을 새로 엽니다. 방금 설치한 명령이 안 잡힐 때 씁니다.

## 파일 패널

칸 위쪽 줄 왼쪽의 폴더 아이콘을 누르면 열립니다. 안에 "파일" 과 "변경사항" 두 탭이 있습니다.
- 파일: 폴더를 펼쳐 보고, 두 번 눌러 파일을 엽니다.
- 변경사항: git 으로 바뀐 파일 목록입니다. 폴더 아이콘의 숫자가 바뀐 파일 수입니다.
- 검색: 돋보기를 누르고 이름을 치면 지금 폴더 안에서 바로 거릅니다. 옆의 문서 아이콘을 켜면
  파일 내용에서 찾습니다.
- 올리기: 컴퓨터의 파일을 파일 패널로 끌어다 놓으면 그 폴더에 올라갑니다.

## 붙여넣기와 파일 보내기

이미지를 터미널에 붙여넣거나 파일을 터미널 위로 끌어다 놓으면, 파일이 올라가고 그 경로가
입력줄에 들어갑니다. 엔터는 직접 누릅니다. 에이전트에게 "이 이미지 보고 고쳐 줘" 처럼 함께 쓰면 됩니다.

## 설정

위쪽 탭 줄 오른쪽 끝의 톱니바퀴를 누릅니다. 글꼴 크기, 테마, 모바일 키 등을 바꿉니다.

## 작업 규칙

- main 브랜치에서는 작업하지 않습니다. 작업마다 브랜치를 따서 합니다(`fix/…`, `feat/…`).
  main 에서 고치려 하면 막히고 브랜치를 따라고 안내가 나옵니다.
- 병합은 PR 로만 합니다. 작업이 끝나면 에이전트에게 "올려줘" 라고 하면 커밋하고 PR 을 엽니다.
- PR 이 병합되면 CI 가 자동으로 새 버전을 만들고 다운로드 페이지도 바뀝니다.

## 터미네이터에게 시키기

위쪽 탭 줄 오른쪽, 설정 왼쪽의 반짝이 아이콘을 누르면 터미네이터 창이 열립니다. 하고 싶은 일을 말로 쓰면 됩니다. 코드를 바꾸는 일이면 터미네이터가 새 탭을 열고 담당
에이전트에게 넘깁니다. 진행은 그 탭에서 보이고, 끝나면 터미네이터가 결과를 알려 줍니다.

## 화면 안내 대상

"어디 있어요?" 에 비출 수 있는 버튼의 id 입니다.
- `terminator`: 위쪽 탭 줄 오른쪽, 설정 왼쪽의 터미네이터(반짝이 아이콘)
- `settings`: 위쪽 탭 줄 오른쪽 끝의 설정(톱니바퀴)
- `quick-input`: 위쪽 탭 줄의 빠른입력(키보드 아이콘, 데스크톱)
- `pane-files`: 칸 위쪽 줄 왼쪽의 파일 패널(폴더 아이콘)
- `files-changes-tab`: 파일 패널 안의 변경사항 탭
- `files-search`: 파일 패널의 검색(돋보기)
- `pane-split`: 칸 위쪽 줄의 분할 아이콘
- `pane-more`: 칸 위쪽 줄 오른쪽 끝의 `…` 메뉴
