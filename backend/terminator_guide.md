# Terminal List 사용 안내

터미네이터가 "어떻게 해요?" 에 답할 때 이 문서만 근거로 씁니다. 여기 없는 버튼이나 설정은
없는 것으로 봅니다. 따옴표 안의 이름은 화면에 보이는 그대로의 이름입니다.

## 화면 구성

브라우저 안의 터미널입니다. 맨 위가 탭 줄이고, 탭 하나에 칸(분할)을 여러 개 둘 수 있습니다.
- 탭 줄 왼쪽 끝: 홈 버튼(터미널 모양 아이콘, 이름 "홈").
- 탭 줄 가운데: 탭들. 각 탭은 번호 타일, 호스트 아이콘, 이름으로 보입니다.
- 탭 줄 오른쪽: "빠른 입력"(키보드 아이콘, PC 만), "브로드캐스트"(칸이 2개 이상일 때), "터미네이터"(반짝이 아이콘), 설정(톱니바퀴, 이름 "시스템 설정").
- 각 칸의 위쪽 줄: 왼쪽부터 이동 핸들(⠿, PC 만), 파일(폴더 아이콘), 현재 경로, 주소 칩(예: 1.2), "최근 명령 보기"(눈 아이콘), "패널 분할"(분할 아이콘), `…`("더 보기").
- 폰에서는 화면 아래에 퀵바(키 줄)가 붙습니다.

## 자주 헷갈리는 것

- 탭 줄에 + 버튼은 없습니다. 새 터미널은 홈에서 엽니다.
- 탭에는 X 버튼이 없습니다. 탭 닫기는 아래 "탭 닫기" 를 봅니다.
- 글꼴(서체)을 바꾸는 설정은 없습니다. 글자 크기만 바꿉니다.
- 설정에 "계정" 탭은 없습니다. 비밀번호·2단계 인증·패스키는 설정 → 일반의 계정 아래에 있습니다.
- tmux 를 쓸지는 호스트마다가 아니라 설정 → 일반 → "세션 멀티플렉서" 한 곳에서 정합니다.
- 도구 설치는 카드의 `⋯`("더보기") 메뉴 안에 있습니다.

## 새 터미널 열기

- 탭 줄 왼쪽 끝의 홈 버튼을 누르면 홈이 나옵니다. 홈의 "현재 머신" 카드를 누르면 이 서버의 터미널이,
  호스트 카드를 누르면 그 기계의 SSH 터미널이 새 탭으로 열립니다. Ctrl+T 도 홈으로 갑니다.
- 원하는 폴더에서 열기: 카드의 폴더 버튼("경로 골라 열기…")을 누르고 폴더를 고릅니다.
- 지금 칸과 같은 폴더에서 하나 더: 칸의 `…` → "같은 경로로 새 터미널 열기". PC 는 새 탭, 폰은 같은 탭에 칸이 하나 더 생깁니다.
- 명령 팔레트(Ctrl+Shift+P)의 "터미널 새로 열기" 도 홈으로 갑니다.
- 폴더를 고르는 창 아래에서 "터미널"(기본 (tmux) / tmux / none)과 "셸"(bash / zsh / sh)을 그 칸 하나에만 고를 수 있습니다.
  안 고르면 설정을 따릅니다. 원격에서 셸을 기본으로 두면 그 호스트의 로그인 셸을 씁니다.

## 탭

- 전환: 탭을 누르거나 Ctrl+1~9.
- 탭 메뉴: PC 는 탭을 오른쪽 클릭, 폰은 활성 탭의 `⋯` 를 누릅니다. 메뉴에는 "이름 변경", "같은 경로로 분할",
  "오른쪽으로 분할", "아래로 분할", "2 × 2 그리드"(분할 셋은 PC 만), "탭 닫기" 가 있습니다.
  원격 데스크톱 탭이면 "VNC 설정" 도 있습니다.
- 이름 변경: 탭 메뉴 → "이름 변경". 바꾼 뒤에는 폴더 이름으로 저절로 바뀌지 않습니다.
- 순서 바꾸기: PC 는 탭을 끌어서, 폰은 길게 누른 뒤 끌어서 옮깁니다.
- 탭 합치기: 탭을 다른 탭의 칸 위로 끌어다 놓습니다. 칸의 가장자리에 놓으면 그쪽으로 나뉘어 들어가고, 가운데에 놓으면 그 칸과 바뀝니다.
- 탭 번호 타일의 표시: 숫자는 칸 수, 깜빡이면 작업 중이나 출력이 있는 것, 빨간 `!` 는 에이전트가 기다리는 것입니다.
  타일이 회색에 빨간 `!` 면 호스트에 연결할 수 없는 것입니다.

## 탭 닫기

탭 가운데를 휠 클릭하거나, 탭 메뉴의 "탭 닫기" 를 누르거나, Ctrl+W 를 누릅니다. "이 탭의 세션이 종료됩니다." 확인이 뜨고,
닫으면 그 탭에서 돌던 작업은 끝납니다. 터미널 안에 커서가 있을 때 Ctrl+W 는 셸로 갑니다. 브라우저가 Ctrl+T·Ctrl+W 를
먼저 가져갈 수도 있습니다.

## 칸 나누기와 정리

- 나누기: 칸 위쪽 줄의 분할 아이콘("패널 분할")을 누르고 "오른쪽으로 분할" 또는 "아래로 분할" 을 고릅니다.
  단축키는 Ctrl+\ (오른쪽), Ctrl+Shift+\ (아래)입니다. 왼쪽·위로 나누는 메뉴는 없습니다.
- 크기 조절: 칸 사이의 경계선을 끕니다(PC). 경계선을 두 번 누르면 그 두 칸이 같은 크기가 됩니다.
- 모두 같은 크기로: PC 에서 탭 안에 있을 때 설정(톱니바퀴) 메뉴의 "패널 균등 분할".
- 칸 옮기기: 칸 위쪽 줄 맨 왼쪽의 ⠿ 핸들을 다른 칸 위로 끕니다. 가장자리면 그쪽으로 나뉘고 가운데면 두 칸이 바뀝니다(PC).
- 칸을 새 탭으로 떼기: 칸의 `…` → "새 탭으로 분리"(칸이 2개 이상일 때).
- 칸 닫기: 칸의 `…` → "세션 종료". 그 칸의 작업은 끝납니다. 마지막 칸이면 탭 닫기와 같습니다.
- 빈 칸: 아래에서 열 곳(현재 머신, 호스트)을 고르거나 "열린 탭을 여기로 옮기기" 로 다른 탭을 가져옵니다.
- 폰에서 칸이 2개 이상이면 위에 번호 칩이 생기고 한 번에 한 칸씩 보입니다. 칩을 눌러 바꾸고, 활성 칩의 `…` 에서
  "이름 변경", "세션 재시작", "경로 지정해 재시작", "이 분할 세션 종료" 를 합니다.

## 칸의 … 메뉴

칸 위쪽 줄 오른쪽 끝의 `…` 를 누르면 나옵니다.
- "세션 종료": 이 칸을 닫습니다. 돌던 작업은 끝납니다.
- "새 탭으로 분리": 이 칸을 따로 떼어 새 탭으로 만듭니다.
- "텍스트로 보기": 화면 내용을 글자로 띄워 원하는 부분을 골라 복사합니다.
- "정보": 오른쪽에 이 칸의 세션·연결·호스트·경로와 서버 상태(CPU, 메모리, 디스크)를 보여 줍니다.
- "테마": 이 칸에만 다른 테마를 입힙니다. "초기화" 로 전체 테마로 돌아갑니다.
- "터미널 새로고침": 화면만 다시 붙입니다. 돌던 작업은 그대로입니다. 화면이 깨졌을 때 씁니다.
- "같은 경로로 새 터미널 열기": 이 칸은 두고 같은 폴더에서 하나 더 엽니다.
- "경로 지정해 재시작": 폴더를 골라 그 자리에서 셸을 새로 엽니다. 돌던 작업은 끝납니다.
- "세션 재시작": 돌던 것을 끝내고 같은 폴더에서 셸을 새로 엽니다. 방금 설치한 명령이 안 잡힐 때 씁니다.
탭 전체를 다시 붙이려면 PC 에서 설정(톱니바퀴) 메뉴의 "현재 탭 새로고침" 을 누릅니다.

## 최근 명령과 스니펫

- 칸 위쪽 줄의 눈 아이콘("최근 명령 보기")을 누르면 이 터미널에 보낸 명령이 나옵니다. 누르면 그 명령을 다시 보내고 실행합니다.
  "히스토리 비우기" 로 지웁니다. ⇆ "다른 세션에서 명령 복사" 로 다른 터미널의 명령을 가져와 여기서 실행합니다.
- 스니펫: Ctrl+Shift+S 로 엽니다(버튼은 없습니다). "스니펫 추가" 로 이름·명령·태그를 저장하고, 고르면 지금 칸에 입력되어 바로 실행됩니다.

## 터미널 안에서

- 복사: 드래그하면 저절로 복사됩니다(PC). Ctrl+Shift+C 도 됩니다. tmux 나 vim 안에서도 끌면 선택됩니다.
- 붙여넣기: Ctrl+V.
- 오른쪽 클릭 메뉴(폰은 길게 누르기): "링크 복사"(링크 위에서), "전체 복사", "붙여넣기", "빠른 입력에 붙여넣기",
  "파일 보내기", "새로고침", "맨 아래로 스크롤", "텍스트로 보기". Shift+오른쪽 클릭은 칸 안의 프로그램으로 갑니다.
- 검색: 터미널 안에서 Ctrl+Shift+F, 또는 명령 팔레트의 "터미널 검색". Enter 다음, Shift+Enter 이전, Esc 닫기.
- 링크: 주소를 누르면 열립니다. 이 서버 칸에서는 `src/app.js:12` 같은 파일 경로를 누르면 에디터로 열립니다(줄 이동은 안 합니다).
- 스크롤바와 질문 고정은 설정 → 일반 → 스크롤 제어에서 켭니다.

## 파일 보내기와 이미지 붙여넣기

- 이미지를 터미널에 붙여넣거나 파일을 터미널 위로 끌어다 놓으면, 그 칸이 있는 기계의 `/tmp/iterminallist-paste/` 에
  올라가고 경로가 입력줄에 들어갑니다. 엔터는 직접 누릅니다. 폴더는 보낼 수 없습니다.
- 오른쪽 클릭 → "파일 보내기" 로 골라 보낼 수도 있습니다.
- 파일 패널의 항목을 터미널로 끌면 업로드 없이 그 경로만 입력됩니다.
- 이미지 옆의 `≈N tok` 은 에이전트가 그 이미지를 읽을 때 드는 대략의 토큰입니다.

## 빠른 입력

긴 글이나 여러 줄을 편하게 써서 터미널로 보냅니다.
- 열기: PC 는 탭 줄의 키보드 아이콘이나 Ctrl+Shift+Enter, 폰은 퀵바 왼쪽의 💬 키.
- 보내기: PC 는 Ctrl+Enter 로 보내고 Enter 는 줄바꿈입니다. 폰은 Enter 로 보내고 Shift+Enter 가 줄바꿈입니다.
- "조합키" 로 바꾸면 Ctrl+C, F5 같은 키 하나를 보냅니다.
- 아래 줄: 붙여넣기, "파일 첨부"(📎), "입력창 비우기", "음성 입력"(🎤), "전송".
- 여러 칸에 한 번에: "보낼 대상"(⌖)에서 칸을 고릅니다. 안 고르면 지금 칸으로 갑니다. 칸이 다른 기계에 있으면 첨부 파일도 기계마다 올라갑니다.
- 닫아도 쓰던 글은 남고, 새로고침해도 이 기기에 남아 있습니다.
- "최근 명령 보기" 에서 고르면 입력창에 넣기만 하고 보내지는 않습니다.

## 브로드캐스트(동시 입력)

탭에 칸이 2개 이상일 때 탭 줄의 "브로드캐스트" 를 켜면, 한 칸에 치는 것이 그 탭의 모든 칸에 들어갑니다(PC).
각 칸에 "동시 입력 중" 표시가 붙고, ✕ "이 분할만 제외" 로 한 칸을 뺍니다. 끄려면 같은 버튼("브로드캐스트 끄기")을 누릅니다.

## 명령 팔레트와 빠른 파일 열기

- 명령 팔레트: Ctrl+Shift+P. "터미널 새로 열기", "시스템 설정", "터미널 검색", "빠른 파일 열기" 네 가지가 있습니다.
- 빠른 파일 열기: Ctrl+P. 이 서버 작업 폴더의 파일을 이름으로 찾아 엽니다. 비워 두면 최근 연 파일이 나옵니다.
- 설정 열기: Ctrl+,

## 파일 패널

칸 위쪽 줄 왼쪽의 폴더 아이콘을 누르면 왼쪽에 열립니다. 아이콘의 숫자는 git 으로 바뀐 파일 수입니다. 원격 칸이면 그 호스트의 파일을 봅니다.
"파일" 과 "변경사항" 두 탭이 있습니다.
- 파일 열기: 한 번 누르면 고르고, 두 번 누르거나 Enter 로 엽니다.
- 위쪽 버튼: "상위 폴더로", "파일 검색...", "변경된 것만 보기", 정렬(이름순/수정일순/크기순), "새 파일", "새 폴더", 업로드,
  "여기서 터미널 열기", "새로고침". 경로 줄을 누르면 경로를 직접 쳐서 이동합니다.
- 검색: "파일 검색..." 은 펼쳐 둔 폴더 안에서 이름으로 거릅니다. 옆의 문서 아이콘을 켜면 "파일 내용 검색" 으로 내용에서 찾습니다(2글자 이상).
- 항목 오른쪽 클릭: "새 파일", "새 폴더", "여기서 터미널 열기", "여기에 업로드", "경로 복사", "이름 복사", "다운로드", "이름 변경", "삭제".
  여러 개를 고르려면 Ctrl+클릭이나 Shift+클릭을 씁니다. F2 는 이름 변경, Delete 는 삭제입니다. 이 서버 파일 여러 개는 ZIP 으로 내려받습니다.
- 올리기: 컴퓨터의 파일을 파일 패널이나 폴더 위로 끌어다 놓습니다.
- 옮기기: 항목을 다른 폴더 위로 끕니다.

## 변경사항과 커밋

파일 패널의 "변경사항" 탭에 git 으로 바뀐 파일이 나옵니다. 파일을 누르면 에디터로 열립니다.
- 오른쪽 클릭: "에디터에서 열기", "변경분"(diff), "파일 탐색기에서 보기".
- 커밋: "커밋" 을 눌러 메시지를 쓰고 "전체 커밋"(Ctrl+Enter)을 누르면 바뀐 것 전부를 커밋합니다. "푸시" 로 올립니다.
- git 저장소가 아니면 "git 저장소 아님" 이 보입니다.

## 에디터

파일을 열면 터미널 위에 에디터가 뜹니다. 아래 막대를 끌어 높이를 바꿉니다.
- 저장: "저장" 또는 Ctrl+S. 서식 정리: Shift+Alt+F(JS, TS, JSON, CSS, HTML, Markdown, YAML).
- "변경분": git 과 다른 파일이면 나란히 비교합니다. "미리보기": md, html, csv, tsv.
- 이미지, PDF, 동영상, 오디오, 엑셀(xlsx)은 바로 보여 줍니다. 원격 HTML 미리보기는 안 됩니다.
- 밖에서 파일이 바뀌면 "외부 변경 감지됨" 이 뜨고 "다시 불러오기" 나 "내용 유지" 를 고릅니다.
- 탭은 휠 클릭이나 닫기로 닫습니다. 저장 안 한 내용이 있으면 확인을 받습니다.

## 홈 화면

홈 위쪽에서 "터미널", "실행 중", "대시보드" 를 바꿔 봅니다.
- 터미널: 기계 카드("현재 머신", 호스트들, "호스트 추가")와 그 아래 세션 목록입니다. 카드는 끌어서 순서를 바꿉니다.
  카드의 `⋯`("더보기")에는 "도구 설치", "원격 데스크톱", "호스트 설정"(현재 머신은 "현재 머신 편집")이 있습니다.
- "실행중인 세션": 지금 열린 탭들입니다. 누르면 그 탭으로 갑니다.
- "이어할 수 있는 세션": 호스트에 남아 있는데 열린 탭이 없는 tmux 세션입니다. 누르면 새 탭으로 붙고,
  🗑 "완전 종료 (세션 kill)" 로 없앱니다(그 안의 작업은 사라집니다). 연결 못 한 호스트는 한 줄로 뜨고 누르면 다시 시도합니다.
- 실행 중: 기계마다 메모리·칸 수·가동 시간과, 모든 칸의 상태(확인 대기, 작업 중, 대기)를 보여 줍니다. 줄을 누르면 그 칸으로 갑니다.
- 대시보드: 터미널 사용 시간과, 설정에서 켰다면 LLM 사용량(토큰, 예상 비용)을 7일/30일/90일/전체로 봅니다.
  비용은 정가 환산이지 실제 청구액이 아닙니다.

## 호스트(SSH 서버) 등록

- 추가: 홈의 "호스트 추가" 카드, 또는 설정 → "호스트 관리" 의 "호스트 추가".
- 연결 탭: "표시 이름", "호스트 / IP"("Tailscale 에서 선택" 가능), "포트", "SSH 사용자", 인증("SSH 키" / "비밀번호" / "Tailscale").
- 세션 탭: "세션 이름", "시작 경로". 저장된 호스트는 "원격 세션 목록" 에서 세션을 종료하거나 "원격 tmux 서버 종료" 를 합니다.
- 테마와 외형 탭: 아이콘, 색상, 터미널 색상.
- 고치기: 카드의 `⋯` → "호스트 설정", 또는 설정 → 호스트 관리에서 그 호스트를 누릅니다. 삭제도 거기서 합니다.
- 현재 머신(이 서버)의 이름·아이콘·색·시작 경로는 카드 `⋯` → "현재 머신 편집" 에서 바꿉니다.
- 호스트에 tmux 가 없으면 칸에 "탭을 닫으면 이 세션은 사라집니다" 안내와 "설치" 버튼이 뜹니다.

## SSH 키

설정 → "SSH 키" 탭에서 "SSH 키 추가" 를 누르고 "표시 이름", "개인키 (PEM)", 필요하면 패스프레이즈를 넣습니다.
키는 이 서버에만 암호화해 보관하고 원격 호스트로 보내지 않습니다. 호스트의 인증을 "SSH 키" 로 두고 그 키를 고릅니다.

## 도구 설치

카드의 `⋯` → "도구 설치" 에서 그 기계에 tmux, itl 같은 도구가 있는지 봅니다("설치됨", "없음", "옛 버전").
"터미널에서 설치" 를 누르면 새 터미널에 설치 명령이 입력되고, 엔터는 직접 누릅니다. "명령 복사" 도 있습니다.
"직접 추가" 로 원하는 도구(이름, 설치 명령, 확인 명령)를 목록에 넣습니다.

## 원격 데스크톱

카드의 `⋯` → "원격 데스크톱". 열린 데스크톱에 붙거나 "새 데스크탑 만들기" 로 해상도를 골라 만듭니다.
VNC 비밀번호가 없으면 6~8자로 먼저 정합니다. 연 뒤에는 탭 메뉴의 "VNC 설정" 에서 "화면 맞춤"/"원본 크기", 해상도, 화질을 바꿉니다.

## 설정

탭 줄 오른쪽 끝의 톱니바퀴를 누르거나 Ctrl+, 를 누릅니다. 탭 안의 PC 화면에서는 작은 메뉴가 먼저 뜨고 "시스템 설정" 을 누릅니다.
탭은 "일반", "모바일", "호스트 관리", "SSH 키", "도움말" 입니다. 일반과 모바일은 아래 "저장" 을 눌러야 반영됩니다.
- 일반 → 계정: "로그아웃", "기본 셸", "세션 멀티플렉서"(tmux 는 끊겨도 세션이 남고, none 은 탭을 닫으면 끝납니다), "현재 머신 시작 경로".
  그 아래 "비밀번호 변경", "2단계 인증", "패스키" 카드가 있습니다.
- 일반 → 테마와 외형: "이북 모드", "자동 절전 화면"(기본 5분), "UI 테마", "언어 설정", "글자 크기 (PC)", "글자 대비".
- 일반 → 터미네이터: Z.ai 키와 모델. 이 칸은 자기 "저장" 버튼으로 따로 저장합니다.
- 일반 → LLM 사용량: "LLM 사용량 대시보드" 켜기(바로 반영), "통화 표기".
- 일반 → 스크롤 제어: "터미널 스크롤바 표시", "스크롤시 입력내용보기", "자동 스크롤", "부드러운 화면 전환", "예측 입력", "스크롤 감도".
- 모바일: "글자크기 (모바일)" 와 퀵바 편집.
- 도움말: 검색되는 도움말과 단축키 목록.
- "초기화" 는 모든 설정을 기본값으로 되돌립니다.

## 로그인과 보안

- 비밀번호 변경: 설정 → 일반 → "비밀번호 변경". 바꾸면 다시 로그인합니다.
- 2단계 인증: 설정 → 일반 → "2단계 인증". QR 을 인증 앱으로 찍고 "확인하고 활성화". 백업 코드는 한 번만 보이니 저장해 둡니다.
  로그인 때 인증 앱 코드 대신 "백업 코드로 로그인" 을 쓸 수 있습니다.
- 패스키: 설정 → 일반 → "패스키" → "패스키 등록". 등록하면 로그인 화면에 "패스키로 로그인" 이 생깁니다.
- 원격 호스트가 2단계 인증 코드를 물으면 칸에 "추가 인증 필요" 창이 뜹니다.

## 테마, 이북 모드, 절전

- 전체 테마: 설정 → 일반 → "UI 테마"(다크/라이트 약 60가지). 칸 하나만: 칸 `…` → "테마"(무작위도 있습니다).
- 이북 모드: 전자잉크 화면용으로 애니메이션과 효과를 끄고 흑백으로 그립니다. 설정 → 일반, 또는 로그인 화면 아래에서 켭니다. 끄면 원래 설정이 돌아옵니다.
- 자동 절전 화면: 정해 둔 시간 동안 입력이 없으면 화면만 쉽니다. 연결과 작업은 그대로이고, 아무 키나 누르면 돌아옵니다(그 키는 터미널로 가지 않습니다).

## 폰에서 쓰기

- 퀵바: 화면 아래의 키 줄입니다. 기본 세트는 💬(빠른 입력), 화살표, ESC, TAB, ⏎(엔터), ⌫(지우기), ^C, CTRL, ALT, SHIFT, 복사, 붙여넣기, 맨 아래로 입니다.
  CTRL·ALT·SHIFT 는 누른 뒤 다음 키 하나에 걸립니다. ⌫ 와 화살표는 길게 누르면 반복됩니다.
- 세트 바꾸기: 퀵바 왼쪽 키보드 아이콘("퀵바 세트 선택"). "Claude · Codex" 세트에는 에이전트에 자주 쓰는 키가 있습니다.
- 퀵바 고치기: 세트 메뉴의 "퀵바 설정", 또는 설정 → "모바일". 키를 추가하고 종류·라벨·내용·위치를 바꾸며, "프리셋 세트 추가" 로
  tmux 키, 기능키, Ctrl/Alt 조합 세트를 넣습니다. 퀵바에서 키를 길게 누른 뒤 옆으로 끌면 순서가 바뀝니다. 설정의 "저장" 을 눌러야 반영됩니다.
- 선택해서 복사: 퀵바의 복사 키를 누르면 선택 모드가 되고, 길게 누르거나 끌어서 고른 뒤 "선택 복사 종료" 를 누르면 복사됩니다.
- 터미널을 길게 누르면 메뉴가 나옵니다. 칸이 여럿이면 위의 번호 칩으로 바꿉니다.
- 폰에서는 칸 나누기 메뉴(오른쪽·아래·2×2)와 브로드캐스트 켜기가 없습니다.

## 연결이 안 될 때

- "다시 연결 중…": 잠깐 끊겨서 저절로 다시 붙는 중입니다. 기다리면 됩니다.
- "호스트에 연결할 수 없습니다": 그 호스트가 꺼졌거나 닿지 않습니다. 사유가 함께 보이고 저절로 다시 시도합니다. "지금 다시 시도" 로 바로 시도합니다.
- "다른 기기에서 접속 중": 같은 세션을 다른 기기가 쓰는 중입니다. "내가 가져오기" 로 가져옵니다.
- "셸이 종료되었습니다": 셸이 끝났습니다. "다시 연결" 은 기존 셸에, "새 셸 시작" 은 새 셸로 붙습니다.
- 화면이 깨졌으면 칸 `…` → "터미널 새로고침", 명령이 안 잡히면 "세션 재시작", 업로드가 계속 막히면 브라우저 새로고침을 합니다.

## 처음 시작과 로그인 명령

처음 들어오면 터미널 첫 화면에 아직 안 한 준비(GitHub 로그인, git 이름·이메일, Claude 로그인)가 표시됩니다. 표시된 명령을 그대로 칩니다.
- GitHub: `gh auth login` 을 치고 안내대로 브라우저에서 승인합니다.
- Claude: `claude` 를 치면 처음 한 번 로그인 화면이 나옵니다.
- Codex: `codex login` 을 칩니다.

## 칸 주소와 itl

각 칸에는 "탭.칸" 주소(예: 1.2)가 있습니다. 칸 위쪽 줄의 주소 칩과 터미널 맨 아래 tmux 줄 왼쪽의 `[1.2]` 가 그것입니다.
주소 칩을 누르면 `itl send 1.2 '…'` 형태가 복사됩니다. 터미널에서 쓰는 itl 명령은 이렇습니다.
- `itl whoami`: 이 칸의 주소를 보여 줍니다.
- `itl list`: 칸 목록을 보여 줍니다.
- `itl doctor`: 보낼 수 있는 상태인지 점검합니다.
- `itl send 1.2 '내용'`: 그 칸에 글을 넣습니다. 다른 기계의 칸도 됩니다. 에이전트가 돌고 있으면 엔터까지, 셸이면 글만 넣습니다.
itl 이 없는 기계는 카드 `⋯` → "도구 설치" 에서 설치합니다.

## 터미네이터

탭 줄 오른쪽, 설정 왼쪽의 반짝이 아이콘을 누르면 열립니다(PC 는 오른쪽 패널, 폰은 아래 시트). Esc 로 닫습니다.
이 화면을 쓰는 법을 물으면 답하고, 버튼 위치를 화면에서 비추고, 누를 수 있는 버튼을 답 아래에 내밉니다.
스스로 무언가를 실행하지는 않습니다. 버튼은 사람이 누릅니다. 코드를 고치거나 명령을 실행하는 일도 하지 않습니다.
그런 일은 터미널을 열어 Claude 나 Codex 에게 맡깁니다. "새 대화" 로 대화를 비웁니다.
키와 모델은 설정 → 일반 → 터미네이터에서 넣고 "연결 확인" 으로 답이 오는지 봅니다.

## 화면 안내 대상

"어디 있어요?" 에 비출 수 있는 버튼의 id 입니다.
- `home`: 위쪽 탭 줄 왼쪽 끝의 홈 버튼(새 터미널도 여기서 엽니다)
- `terminator`: 위쪽 탭 줄 오른쪽, 설정 왼쪽의 터미네이터(반짝이 아이콘)
- `settings`: 위쪽 탭 줄 오른쪽 끝의 설정(톱니바퀴)
- `quick-input`: 위쪽 탭 줄의 빠른입력(키보드 아이콘, 데스크톱)
- `pane-files`: 칸 위쪽 줄 왼쪽의 파일 패널(폴더 아이콘)
- `files-changes-tab`: 파일 패널 안의 변경사항 탭
- `files-search`: 파일 패널의 검색(돋보기)
- `pane-split`: 칸 위쪽 줄의 분할 아이콘
- `pane-more`: 칸 위쪽 줄 오른쪽 끝의 `…` 메뉴
