기능

필요한 건 다 있습니다

🖥️

지속형 tmux 세션

브라우저를 닫아도 세션이 유지됩니다. 재접속 시 자동으로 재연결.

📁

Monaco 파일 편집기

VS Code 엔진 기반 파일 탐색기와 에디터. 워크스페이스 범위로 안전하게 격리.

🎙️

음성 입력

빠른입력 패널에서 마이크 버튼으로 명령어 음성 입력. Web Speech API 활용.

🔑

패스키 / Passkey

Face ID, Touch ID, 하드웨어 키로 로그인. TOTP 2FA와 병행 사용 가능.

📋

명령 이력

터미널별 명령 이력 무한 스크롤. 항목 클릭으로 커서 위치에 바로 삽입.

🔐

SSH 관리

SSH 호스트와 키 관리. Fernet 암호화 vault에 비밀번호·패스프레이즈 보관.

📱

모바일 친화적

롱프레스 컨텍스트 메뉴, 탭으로 iOS 키보드 호출, 터치 전용 툴바.

🔒

보안

단일 관리자 계정, JWT 세션, TOTP 2FA, Fernet vault 암호화.

🐳

Docker / Host-native

GHCR 이미지로 즉시 배포 또는 systemd로 호스트 직접 설치. 둘 다 지원.

설치

30초 설치

기본 포트 38822 — 일반 개발 포트(3000, 8080, 8888)와 충돌 없음.

bash
$ git clone https://github.com/jshsakura/oc-terminal-list.git
$ cd oc-terminal-list
$ docker compose up -d

# → http://localhost:38822
bash
$ git clone https://github.com/jshsakura/oc-terminal-list.git && cd oc-terminal-list
$ cp .env.example .env # 경로 편집
$ python3 -m venv .venv && .venv/bin/pip install -r backend/requirements.txt
$ cd frontend && npm install && npm run build && cd ..
$ sudo cp deploy/iterminallist.service /etc/systemd/system/
$ sudo systemctl enable --now iterminallist.service

# → http://localhost:38822
